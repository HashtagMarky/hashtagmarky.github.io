---
name: "The Post TARC Update"
---

A brand new release to Jurassic PokéPark, introducing a host of new features and the squishing of a few pesky bugs.
- *Achievements*: Adds an achievement system that persists between multiple runs to be used to track progress. **See if you can complete them all!** 
- *Graphics overhaul*: Replace all overworld sprites with high quality, and higher frame spritesheets in the Pokémon Mystery Dungeon Style.
- *Upgraded UI*: Improve many user interfaces, unifying and making them more streamlined.
- *Improved Puzzles*: Adjust some puzzles to have clearer complete conditions.
- *AutoSaving*: Better timed and more frequent autosaving in order to reduce punishment for a 'Game Over'.
- *Early Player Feedback*: Implement a lot of the feedback from release day players.
